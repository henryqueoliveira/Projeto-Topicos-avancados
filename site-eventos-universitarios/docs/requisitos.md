# Lista de Requisitos

## Requisitos funcionais

- RF01 — O site deve permitir cadastro de usuário.
- RF02 — O site deve permitir login do usuário.
- RF03 — O site deve exibir uma página inicial com eventos em destaque.
- RF04 — O usuário deve conseguir visualizar a listagem de eventos.
- RF05 — O usuário deve conseguir pesquisar e filtrar eventos.
- RF06 — O site deve apresentar uma página de detalhes de cada evento.
- RF07 — O participante autenticado deve conseguir se inscrever em um evento.
- RF08 — O site deve apresentar uma confirmação após a inscrição.
- RF09 — O participante deve possuir uma área de “Minhas Inscrições”.
- RF10 — O participante deve possuir um perfil.
- RF11 — O organizador deverá possuir um painel para gerenciamento.
- RF12 — O organizador deverá conseguir cadastrar eventos.
- RF13 — O organizador deverá conseguir acompanhar os inscritos.
- RF14 — O sistema deverá evoluir para controle de presença.
- RF15 — O sistema deverá evoluir para disponibilização de certificados digitais.
- RF16 — O sistema poderá enviar notificações e lembretes.

## Requisitos não funcionais

- RNF01 — O site deve ser responsivo para celular e computador.
- RNF02 — O sistema deve possuir requisitos básicos de segurança e privacidade.
- RNF03 — O código deve ser versionado com Git.
- RNF04 — Alterações devem seguir o fluxo de branches definido pela equipe.
- RNF05 — Funcionalidades devem ser testadas antes de chegar à branch `main`.
- RNF06 — O processo de entrega deve permitir evolução contínua do produto.
